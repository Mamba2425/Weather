# Telegram Weather Bot

Умный Telegram-бот прогноза погоды с поддержкой:
- Текущей погоды по любому городу мира
- Прогноза на 5 дней
- Геолокации
- Картинок и описаний
- Кнопок выбора популярных городов

## Установка

```bash
pip install -r requirements.txt
python weather_bot.py
```

## Переменные окружения

Создай `.env` или добавь в систему:

- `TELEGRAM_TOKEN` — токен от @BotFather
- `WEATHER_API_KEY` — ключ с openweathermap.org
